# GitHub Copilot — AI Pair Programming

## What It Is
GitHub Copilot is an AI pair programmer that helps developers write code faster. It provides real-time code suggestions, generates entire functions from comments, answers questions in chat, reviews pull requests, and can even build multi-file features autonomously with coding agent mode.

## The Technical Reality
- **Code completions**: Suggests lines or blocks of code as you type
- **Copilot Chat**: Natural language Q&A about code, errors, and architecture
- **Copilot code review**: Automated first-pass code review on PRs
- **Coding agent**: Autonomous multi-file coding from an Issue description
- **Context-aware**: Understands the current file, project structure, and related files
- **Multi-language**: Works across 20+ languages (best in Python, JavaScript, TypeScript, Go, Java, C#)

## Common Customer Questions

**Q: Is our code used to train the model?**
A: No. Copilot Business and Enterprise do not use customer code for model training. Code snippets sent for suggestions are not retained. GitHub provides contractual commitments on data handling.

**Q: How does Copilot compare to ChatGPT or Cursor?**
A: Copilot is purpose-built for coding and integrated into the GitHub platform. It understands your repo context, runs inside your IDE, reviews PRs natively, and connects to GitHub Issues and Actions. ChatGPT is a general-purpose AI; Cursor is an alternative IDE. Copilot is the only solution that spans the full development lifecycle from planning to deployment.

**Q: Can we control what Copilot suggests?**
A: Yes. Enterprise admins can exclude specific files or repositories from Copilot context, set organization-wide policies, manage which Copilot features are enabled, and configure content exclusion rules.
